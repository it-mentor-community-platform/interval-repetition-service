# Interval Repetition Service






### Основная информация





Сервис для интервального повторения вопросов к собеседованиям. Предоставляет возможность повторять теоретические вопросы и отслеживать прогресс.








## Стек





- Spring Boot 3


- Java 21


- PostgreSQL

### Локальный запуск

**Через консоль**

./gradlew bootRun --args='--spring.profiles.active=ide'

**В IntelliJ IDEA**
        
Run -> Edit Configurations....

В поле Active profiles введите имя профиля: ide
