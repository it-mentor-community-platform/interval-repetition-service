# Interval Repetition Service






### Основная информация





Сервис для интервального повторения вопросов к собеседованиям. Предоставляет возможность повторять теоретические вопросы и отслеживать прогресс.








## Стек





- Spring Boot 3


- Java 21


- PostgreSQL
